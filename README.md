Nationwide Mitigation of Voltage Sags and Flickering
* The Current Issue: Peak cooling hours or large neighborhood appliances kicking on simultaneously cause widespread voltage sags (low voltage) across localized distribution lines. [3] 
* The FluxGuard Impact:
   Because millions of households would have their inductive motor spikes suppressed locally, the grid would be freed from sudden, random current surges. Neighborhood transformers would breathe easier, virtually eliminating localized brownouts and the annoying light flickering common in provincial areas.
